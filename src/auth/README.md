# Локальные JWT-ключи

Из корня проекта:

```bash
make keys
```

Создаются `certs/private_key.pem` и `certs/public_key.pem` для RS256.
Существующая пара проверяется: оба файла должны содержать соответствующие друг другу
RSA-ключи. Генератор не перезаписывает ключи, в том числе повреждённые или несовпадающие.
При наличии только одного файла восстанови соответствующий второй ключ.
Каталог `certs/` исключён из Git. Старая дополнительная пара сохранена в
`certs/legacy/` и приложением не используется.

Пароли обрабатываются отдельно в `passwords.py` и не требуют JWT-ключей.
JWT-функции читают ключи при вызове, а не при импорте модуля.
HTTP-зависимость `get_current_user` находится в `src/api/dependencies.py`.
