# Локальные JWT-ключи

Из корня проекта:

```bash
make keys
```

Создаются `src/certs/private_key.pem` и `src/certs/public_key.pem` для RS256.
Существующая пара не перезаписывается. При наличии только одного файла восстанови
соответствующий второй ключ. Каталог `certs/` исключён из Git.

Пароли обрабатываются отдельно в `passwords.py` и не требуют JWT-ключей.
JWT-функции читают ключи при вызове, а не при импорте модуля.
